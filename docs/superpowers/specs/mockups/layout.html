NightMap — how much screen should the map take?

Hologram style (B). The game keeps running behind the map and V can still drive, so the layout decides how much of the road you can still see. Each mockup is a 16:9 game frame with the map overlaid.

A — Full screen, translucent

Map covers everything; the game shows through. Most map area, but you're driving "through" the map. Opacity adjustable.

B — Centered panel

Large framed window (~70% of the screen) with holo corner brackets. Game edges stay visible; feels like a projected display.

C — Side panel

Right ~40% of the screen, full height. The road ahead stays clear — best for navigating while driving.
