NightMap — pin and cluster style

Zoomed-in crop of the map panel. Same pins in each: quests (yellow), gigs (pink), vendors, fast travel, an undiscovered "?", the selected pin, and two clusters. In-game the glyphs will be the game's own mappin icons recolored — the shapes here stand in for them.

A — Minimal rings

Thin ring + dot, small type tag. Cluster = dashed ring with a count. Lightest and calmest; types are told apart mostly by color.

B — Game icons in rings

The game's own icon inside a holo ring, tinted by category. Cluster ring is split into colored arcs showing what's inside (e.g. mostly gigs).

C — Hex chips

Filled hexagon badges with the icon, strongest contrast against busy map areas. Cluster = larger hex with count and a fan of the top 3 icons.
